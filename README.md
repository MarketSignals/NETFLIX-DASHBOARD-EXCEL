# Netflix Dashboard (Excel)

## Project Overview

This project is an interactive Netflix Dashboard created in Microsoft Excel using Pivot Tables, Pivot Charts, KPIs, and Slicers.

## Features

- Interactive KPI Cards
- Total Watch Hours
- Completed Titles
- Average Rating
- Movies vs TV Shows
- Watch Status Analysis
- Top Genres
- Top Countries
- Monthly Watch Hours Trend
- Duration Distribution
- Interactive Slicers

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Conditional Formatting
